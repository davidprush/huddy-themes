# Change Log

## 1.0.1

- Soft-contrast update from HUDdy Soft Contrast Spec 1.0: lifted background (`#080e19`), surface and panel, body text `#c2cfdc`, ink-high / ANSI 15 / selection text `#d6e4f2` in place of `#ffffff`, hairline `#1b2e41`, and text on accent `#080e19`. Accents and status colours are unchanged.

## 1.0.0

- First release of HUDdy for Visual Studio Code: workbench colours, terminal ANSI palette, TextMate token colours and semantic token colours, from the NuzeHub TUI 0.2.2 HUDdy palette.
