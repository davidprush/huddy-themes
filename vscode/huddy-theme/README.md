# HUDdy Theme for Visual Studio Code

## A dark heads-up-display theme, matched to the HUDdy apps.

HUDdy is the colour scheme behind NuzeHub, Dirlume and SSHush: a soft-navy `#080e19` canvas, deeper navy panels, and a cyan `#5ee1ff` accent with green, amber and red status colours. This extension brings the same palette to the editor, sidebars, terminal and syntax highlighting. Matching HUDdy themes are available for Ghostty, bpytop/btop and Obsidian.

| Role | Colour |
| --- | --- |
| Background | `#080e19` |
| Panels | `#0d192c` / `#112138` |
| Accent | `#5ee1ff` |
| Text | `#c2cfdc` (headings / ink-high `#d6e4f2`, muted `#7d93ad`) |
| OK / warn / danger | `#3dffa8` / `#ffb547` / `#ff5470` |
| Text on accent | `#080e19` |

### ☞ How to install HUDdy for Visual Studio Code:

Using the official VS Code Extension Marketplace, HUDdy can be installed with one click.

```
1. Extensions ‣ Search for 'HUDdy' ‣ Install
2. Command Palette ‣ Preferences: Color Theme ‣ HUDdy
```

Open the extension marketplace by clicking on the Extensions icon of the Activity Bar. Search for `HUDdy` and click on the `Install` button.

#### Activation

To activate the theme click on the gear icon in the bottom left of the Activity Bar and select Themes ‣ Color Theme. Search for `HUDdy` and confirm the color theme change with `Enter`.

#### Semantic highlighting

HUDdy turns on semantic highlighting, so languages with a semantic token provider (TypeScript, Python with Pylance, Rust, Go and others) get richer colouring for types, parameters and read-only values.
